# Model 411 | MU Forecast Lab

ดับเบิลคลิก **Start Model 411.cmd** หรือรันคำสั่งนี้ในโฟลเดอร์โปรเจกต์

```powershell
npm start
```

เปิด [http://127.0.0.1:4110](http://127.0.0.1:4110) และเปิดหน้าต่างคำสั่งค้างไว้ กด **Present** เพื่อขยายกราฟและซ่อนส่วนจัดการไฟล์ เว็บรันในเครื่องด้วย Node.js 22 ขึ้นไป

## โหลดและอ่านข้อมูล

- เปิดเว็บแล้วจะเห็นผลที่คำนวณจาก CSV ทั้ง 6 ไฟล์ใน `data/` ทันที ราคาปิดล่าสุดในชุดนี้คือ 12 ตุลาคม 2026 ตามวันที่ในไฟล์
- ใช้ **อัปเดตข้อมูล → รวมกับประวัติเดิมและบันทึก** เพื่ออัปโหลดเฉพาะข้อมูลที่เพิ่มหรือแก้ไขโดยไม่ต้องมี API key กดดาวน์โหลดแม่แบบในหน้าต่างนี้ได้
- **ราคา** ใช้ชื่อ `mu_prices.csv` และคอลัมน์ `date,open,high,low,close,volume` เพิ่มทุกวันซื้อขายที่ขาดต่อจากชุดเดิมและใช้เกณฑ์การปรับราคาแบบเดียวกับประวัติ วันที่ซ้ำกับประวัติจะใช้ค่าที่นำเข้า
- **งบ** ใช้ `mu_quarterly_update.csv` ใส่วันสิ้นไตรมาส `fiscalDateEnding` และวันประกาศ `reportedDate` เป็น `YYYY-MM-DD` ไตรมาสใหม่ต้องมีรายได้ `totalRevenue` กระแสเงินสดจากการดำเนินงาน `operatingCashflow` และรายจ่ายลงทุน `capitalExpenditures` ใช้ตัวเลข USD เต็มโดยไม่ใส่ตัวคั่นหลัก ช่องเสริมเว้นว่างได้ ระบบใช้การเติมค่าขาดหายของโมเดลเดิมเมื่อไตรมาสใหม่มีข้อมูลไม่ครบ
- เมื่อต้องการแก้ไตรมาสเดิม ให้ใช้วันสิ้นไตรมาสและวันประกาศที่บันทึกอยู่ในชุดเดิม ใช้ตัวเลขที่เปิดเผย ณ วันประกาศนั้น หากเป็นการปรับย้อนหลังในรายงานรอบถัดไป การใส่ทับไตรมาสเดิมอาจทำให้ Backtest เห็นข้อมูลก่อนวันเผยแพร่จริง ส่วน Macro และไฟล์งบ raw เดิมอัปโหลดแยกได้ตามรายชื่อที่รองรับ
- โมเดลคำนวณ FCF จากกระแสเงินสดจากการดำเนินงานลบค่าสัมบูรณ์ของ CapEx วันที่พร้อมใช้ของงบและ Macro จะแสดงใต้กราฟ หากวันประกาศงบใหม่อยู่หลังวันราคาปิดล่าสุด โมเดลจะใช้ข้อมูลที่พร้อม ณ วันราคาปิด
- เมื่อรันโหมดรวมข้อมูลสำเร็จ ระบบบันทึกข้อมูลรวมและผลคาดการณ์ไว้ใน `data/mu.working.json` การเปิดเว็บหรืออัปเดตครั้งถัดไปจะใช้ชุดนี้ หากต้องการย้อนกลับ ให้ปิดเซิร์ฟเวอร์แล้วเปลี่ยนชื่อไฟล์นี้เก็บเป็นสำรอง
- โหมด **รันจากชุดไฟล์ใหม่** ยังรับ `mu_prices.csv` อย่างเดียวหรือครบ 6 ไฟล์ และแสดงผลเฉพาะเซสชันนั้น ไฟล์ราคาของโหมดนี้ต้องมีอย่างน้อย 1,100 วันซื้อขายหลังทำความสะอาด
- **Forecast** แสดงราคาปิดย้อนหลังและจุดคาดการณ์ที่ 21, 63 หรือ 126 วันซื้อขาย เส้นประเชื่อมจากราคาปิดล่าสุดไปยังจุดปลายช่วง
- **Backtest** แสดงราคาจริง ราคาที่โมเดลเคยทำนาย และ Baseline ที่มี RMSE ต่ำที่สุดในชุดทดสอบ ผลจากชุดตั้งต้นทั้ง 9 คู่ช่วงเวลาและชุดตัวแปรยังมี RMSE สูงกว่า Baseline
- ตัวเลขเป็นผลจากไฟล์ CSV ในโปรเจกต์หรือที่เลือกอัปโหลด วันที่ในหน้าเว็บจึงอ้างอิงข้อมูลชุดนั้น

## ติดตั้ง Python สำหรับรันโมเดล

เครื่องนี้มี Python และไลบรารีใน `.runtime/venv` แล้ว หากย้ายโฟลเดอร์หรือใช้เครื่องอื่น ให้สร้าง environment ใหม่ด้วย Python 3.12

```powershell
py -3.12 -m venv .runtime/venv
& ./.runtime/venv/Scripts/python.exe -m pip install -r requirements.txt
npm start
```

หากใช้ Python ที่ติดตั้งไว้ในตำแหน่งอื่น ให้ตั้ง `MODEL_PYTHON` เป็นพาธของ executable ก่อนเปิดเซิร์ฟเวอร์

## โมเดลและการเพิ่มหุ้น

`models/mu.py` ใช้เซลล์สร้างตัวแปรและประเมินผลจากโน้ตบุ๊กเดิม โดยใช้ chronological walk-forward, purge ข้อมูลตามวันที่เป้าหมาย และประเมินช่วงทดสอบที่กันไว้ หลังเลือกอัลกอริทึมในแต่ละคู่ช่วงเวลาและชุดตัวแปรแล้ว ระบบฝึกซ้ำด้วยแถวที่ทราบผลจริง ณ วันปิดล่าสุดเพื่อคาดการณ์ ผลที่แสดงใน Backtest มาจากโมเดลก่อนฝึกซ้ำ

วิธีเตรียม Macro และวันประกาศงบใช้สมมติฐานเดิมในโน้ตบุ๊ก ค่า RMSE ของการรันใหม่อาจต่างจากผลที่บันทึกในโน้ตบุ๊กเล็กน้อยตามเวอร์ชันไลบรารี และช่วงทดสอบรายวันของระยะ 3 และ 6 เดือนมีช่วงเป้าหมายซ้อนทับกัน

เพิ่ม adapter ใน `models/` และลงทะเบียนใน `models/run.py` จากนั้นเพิ่มสัญลักษณ์ ชื่อบริษัท สกุลเงิน และชื่อไฟล์ใน `server.mjs` ตัวเลือกหุ้นบนหน้าเว็บอ่านจาก registry ผ่าน API ให้ adapter ส่ง JSON ตามโครงสร้าง `public/mu.json` โดยแต่ละรายการใน `results` มี horizon, sessions, forecast, return, metrics และแถว `test` รูปแบบ `[targetDate, actualClose, predictedClose, baselineClose]` จากนั้นวางไฟล์ใน `data/` และรัน `npm run refresh` เพื่อสร้างผลเริ่มต้น

[เอกสาร TimeSeriesSplit ของ scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)

แหล่งงบสำหรับกรอกแม่แบบดูได้จาก [ผลประกอบการรายไตรมาสของ Micron](https://investors.micron.com/financials/quarterly-results/) หากต้องการดึงงบอัตโนมัติในอนาคต [SEC EDGAR](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) มี API สาธารณะที่ใช้ได้โดยไม่ต้องมี key ส่วนราคา OHLCV ต้องมาจากไฟล์ราคาหรือผู้ให้บริการข้อมูลตลาด

## อัปเดตจากอินเทอร์เน็ต

กด **อัปเดตออนไลน์และคำนวณใหม่** เพื่อดึง OHLCV รายวันจาก Yahoo Finance งบ MU จาก SEC EDGAR และ Macro จาก FRED จากนั้นระบบรันโมเดลเดิมและบันทึกผลในเครื่อง ต้องเชื่อมต่ออินเทอร์เน็ตและอาจใช้เวลาหลายนาที หากแหล่งข้อมูลล้มเหลว ระบบจะแสดงข้อผิดพลาดและเก็บผลที่บันทึกสำเร็จไว้

ระบบดึงประวัติราคา 5 ปีใหม่ทั้งหมดเพื่อให้การปรับปันผลและ split อยู่บนฐานเดียวกัน ใช้เฉพาะแท่งวันที่ปิดตลาดแล้ว โดยเผื่อหลังตลาดปิด 15 นาที งบใช้ 10-Q/10-K ตามวันที่สิ้นงวดจริง และถือว่าพร้อมใช้หลังวันยื่น SEC หนึ่งวัน ข้อมูลกระแสเงินสดสะสมและรายได้สะสมแปลงเป็นรายไตรมาสด้วยผลต่างของงวดที่มีจุดเริ่มต้นเดียวกัน FCF ใช้ Operating cash flow ลบ CapEx จึงอาจต่างจาก Adjusted FCF ที่บริษัทเผยแพร่

แหล่ง SEC มีตัวแปรบางรายการไม่ครบ เช่น EPS estimate และ surprise รวมถึง EPS รายไตรมาสที่ไม่มีข้อมูลตรง โมเดลใช้กระบวนการเติมค่าขาดหายเดิม Macro ดึงจากตารางข้อมูลสาธารณะ FRED โดยไม่ใช้ API key และแสดงงวดล่าสุดกับค่าที่โมเดลใช้ใต้กราฟ แหล่งข้อมูลฟรีอาจจำกัดการเรียกหรือเปลี่ยนรูปแบบได้

[Yahoo Finance MU](https://finance.yahoo.com/quote/MU/) · [SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)


Macro ทั้งห้าตัวจับคู่กับ CPIAUCSL, FEDFUNDS, UNRATE, GS10 และ GDPC1 ตามลำดับ ใช้ระดับ CPI และ Real GDP หน่วยเดิม และอัตราดอกเบี้ย/ว่างงานเป็นเปอร์เซ็นต์ GS10 เป็นค่าเฉลี่ยรายเดือนของผลตอบแทนพันธบัตร 10 ปี GDP เป็นรายไตรมาส จึงเลื่อนวันที่จากต้นไตรมาสไปต้นไตรมาสถัดไปก่อนให้กระบวนการเดิมเลื่อนอีกหนึ่งเดือน ใช้ forward fill ระหว่างงวดที่ประกาศ ไม่มีการ interpolate ด้วยข้อมูลไตรมาสถัดไป

การเลื่อนหนึ่งเดือนเป็น proxy ตามโน้ตบุ๊ก ไม่ใช่วันประกาศจริงรายตัว ประวัติที่ดึงเป็นข้อมูลฉบับล่าสุดซึ่งอาจแก้ไขย้อนหลัง จึงยังมีข้อจำกัดสำหรับ Backtest แบบ point-in-time ปุ่มออนไลน์จะบันทึกข้อมูลและผลใหม่หลังดึงครบและคำนวณสำเร็จเท่านั้น หาก FRED ชุดใดล้มเหลวจะแสดงชื่อชุดนั้นและเก็บผลก่อนหน้าไว้

แหล่ง Macro [FRED](https://fred.stlouisfed.org/) ใช้ตารางสาธารณะ /data/{series} เนื่องจากช่อง graph.csv ไม่พร้อมใช้งานในการทดสอบครั้งนี้
